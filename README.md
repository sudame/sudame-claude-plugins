# sudame-claude-plugins

sudame 個人用の [Claude Code](https://claude.com/claude-code) プラグイン marketplace。

## インストール

```
/plugin marketplace add sudame/sudame-claude-plugins
```

## プラグイン一覧

いまはプラグインがありません。

以前あった `gwq` プラグインは消しました。worktree の操作には、代わりに [ghq-worktree](https://github.com/sudame/ghq-worktree) を使います。`ghq-worktree install claude-code` で、Claude Code のフックとスキルが入ります。
